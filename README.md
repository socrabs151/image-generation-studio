# Image Generation Studio

[![CI](https://github.com/socrabs151/image-generation-studio/actions/workflows/ci.yml/badge.svg)](https://github.com/socrabs151/image-generation-studio/actions/workflows/ci.yml)
[![Python](https://img.shields.io/badge/python-3.11%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Десктопное приложение для генерации и редактирования изображений через несколько
агрегаторов-провайдеров (AITUNNEL, Polza.ai) в одном окне.

> **Статус:** рабочая версия. Оба провайдера подключены, генерация, история, просмотр
> документации и темы работают. Список известных дефектов — в
> [docs/known-issues.md](docs/known-issues.md).

## Возможности

- Два агрегатора за единым интерфейсом `Provider`: AITUNNEL и Polza.ai. Подключение
  нового агрегатора сводится к одному модулю, ключи и каталоги хранятся раздельно.
- Генерация изображений и работа по референсу (image-to-image), в том числе сразу с
  несколькими референсами: добавление файлов, drag & drop, `Ctrl+V`, удаление
  отдельного изображения.
- Несколько изображений за запрос (`n`).
- Каталог моделей с диапазонами цен в рублях, проверка баланса, кеш каталога.
- Параметры моделей берутся из каталога провайдера; обязательные параметры проверяются
  до отправки, чтобы не платить за заведомо отклонённый запрос.
- Оценка стоимости и подтверждение перед дорогим запросом, лимит расходов за сессию.
- История генераций: параметры запроса, превью результатов, поиск, фильтры, сортировка,
  итоги и экспорт в CSV/JSON.
- Просмотр результата с зумом и навигацией, просмотрщик вендорской документации.
- Светлая и тёмная темы.

## Требования

- Python 3.11+
- PySide6 (Qt 6), requests, markdown-it-py, Pygments

## Установка (для разработки)

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate

pip install -e ".[dev]"
```

## Запуск

```bash
python -m app
```

При первом запуске создаётся каталог `data/` с файлом `data/settings.json` — ключи
API и настройки хранятся только на вашем компьютере и в репозиторий не попадают.
Впишите ключи в **Settings → Aggregators**, затем выберите провайдера в верхней панели.

Настройки, история, кеш каталога и лог лежат в `data/`, файлы результатов — в папке из
настроек (по умолчанию `Pictures/Image Generation Studio`).

## Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| `Ctrl+Enter` | Сгенерировать (работает и на цифровой клавиатуре) |
| `Ctrl+V` | Добавить изображение из буфера обмена в референсы |
| `Delete` | Очистить референсы |

## Документация агрегаторов

Справочники AITUNNEL и Polza.ai не входят в репозиторий: они принадлежат владельцам
сервисов и обновляются на их стороне. Скачать их можно одним скриптом:

```bash
python scripts/fetch_docs.py                    # оба агрегатора
python scripts/fetch_docs.py --provider polzaai # только Polza.ai
python scripts/fetch_docs.py --force            # обновить уже скачанные файлы
```

Файлы появятся в `docs/aitunnel/` и `docs/polzaai/`. Эти папки не коммитятся — скрипт
можно запускать повторно, уже существующие файлы не перезаписываются без `--force`.

То же самое можно сделать из приложения: **Документация → Load AITUNNEL docs** (или
Polza.ai) — кнопки появляются, только если папки агрегатора ещё нет.

## Проверки

```bash
ruff check .     # линтер
pytest -q        # тесты
```

CI (GitHub Actions) выполняет обе проверки на каждый push и pull request, на Python 3.12
и Linux. Проверка типов и сборка пакета пока не выполняются — см.
[docs/known-issues.md](docs/known-issues.md).

## Структура проекта

```
app/
├── core/         # доменные модели, ошибки, тарифы (без Qt и сети)
├── providers/    # провайдеры агрегаторов (base, aitunnel, polza, http_utils)
├── services/     # настройки, история, каталог, генерация, документация (без Qt)
├── ui/           # окно, темы, виджеты, панели, диалоги
├── workers.py    # фоновые задачи
└── logging_setup.py
resources/
├── themes/       # светлая и тёмная темы (QSS)
└── icons/
scripts/          # служебные скрипты (загрузка документации)
docs/             # наша документация; вендорские справочники не коммитятся
data/             # настройки, история, кеш каталога, лог (создаётся при запуске)
tests/            # pytest
```
