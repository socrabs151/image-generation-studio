# Image Generation Studio

Десктопное приложение для генерации и редактирования изображений через несколько
агрегаторов-провайдеров (AITUNNEL, Polza.ai) в одном окне.

> **Статус:** ранняя разработка. Реализован каркас проекта; функциональный код
> отсутствует.

## Планируемые возможности

- Мульти-провайдерная архитектура: единый интерфейс `Provider`; подключение нового
  агрегатора сводится к одному модулю.
- Генерация изображений и правка по референсу (image-to-image).
- Несколько изображений за запрос (`n`), каталог моделей с диапазонами цен,
  проверка баланса.
- Светлая и тёмная темы.

## Требования

- Python 3.11+
- PySide6 (Qt 6), requests, markdown-it-py

## Установка (для разработки)

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate

pip install -e ".[dev]"
```

## Документация агрегаторов

Справочники AITUNNEL и Polza.ai не входят в репозиторий: они принадлежат владельцам
сервисов и обновляются на их стороне. Скачать их можно одним скриптом:

```bash
python scripts/fetch_docs.py                    # оба агрегатора
python scripts/fetch_docs.py --provider polzaai # только Polza.ai
python scripts/fetch_docs.py --force            # обновить уже скачанные файлы
```

Файлы появятся в `docs/aitunnel/` и `docs/polzaai/`. Эти папки не коммитятся — скрипт
можно запускать повторно, уже существующие файлы не перезаписываются без `--force`.

То же самое можно сделать из приложения: **Документация → Load AITUNNEL docs** (или
Polza.ai) — кнопки появляются, только если папки агрегатора ещё нет.

## Структура проекта

```
app/
├── core/         # доменные модели, ошибки, тарифы (без Qt и сети)
├── providers/    # провайдеры агрегаторов (base, aitunnel, polza)
├── services/     # настройки, история, каталог, генерация, документация (без Qt)
├── workers.py    # фоновые задачи
└── ui/           # окно, темы, виджеты, панели, диалоги
resources/themes/ # светлая и тёмная темы (QSS)
scripts/          # служебные скрипты (загрузка документации)
tests/            # pytest
```
