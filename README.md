# Image Generation Studio

Десктопное приложение для генерации и редактирования изображений через несколько
агрегаторов-провайдеров (AITUNNEL, Polza.ai и другие) в одном окне.

- **Мульти-провайдерность** — единый интерфейс `Provider`, подключение нового агрегатора = новый модуль.
- **Генерация и правка по референсу** — загрузите изображение, напишите промпт.
- **n картинок за раз**, каталог моделей с ценами «от…до», проверка баланса.
- **Документация агрегаторов** — просмотр md прямо в приложении.
- **История и настройки** — сохраняются в JSON.
- **Темы** — светлая и тёмная.

## Статус

Ранняя разработка. Каркас проекта и макет интерфейса готовы; основной код
реализуется по этапам M1–M4.

## Стек

Python 3.11+, PySide6 (Qt 6), requests, markdown-it-py.

## Установка

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate

pip install -e ".[dev]"
```

## Запуск

```bash
python -m app
```

## Разработка

```bash
ruff check .     # линтер
pytest -q        # тесты
```

CI (GitHub Actions) прогоняет обе проверки на каждый push и pull request.

## Структура

```
app/
├── core/         # доменные модели, ошибки, тарифы (без Qt/сети)
├── providers/    # провайдеры агрегаторов (base, aitunnel, polza)
├── services/     # настройки, история, каталог, генерация (без Qt)
├── workers.py    # фоновые задачи
└── ui/           # окно, темы, виджеты, панели, диалоги
resources/themes/ # светлая и тёмная темы (QSS)
docs/             # документация агрегаторов
tests/            # pytest
```
