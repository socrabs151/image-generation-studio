## [Unreleased]

### Added

- Провайдер AITUNNEL: публичный каталог моделей, синхронная генерация изображений,
  проверка баланса аккаунта.
- Интерфейс (PySide6): выбор модели с ценами, ввод промпта, область референса
  (drag & drop и Ctrl+V), панель параметров, сетка результатов и лог.
- Диалог настроек, окно истории генераций и встроенный просмотр документации
  агрегаторов.
- Локальное хранилище данных с автобутстрапом: настройки, история и кеш каталога
  в каталоге `data/`.
- Светлая и тёмная темы.
- Выполнение сетевых и файловых операций в фоне, с возможностью отмены.
- Набор тестов ядра, провайдера и сервисов (pytest).
- Цены и баланс отображаются в рублях; баланс показывает остаток бюджета.
- Легенда обозначений в списке моделей (`refs`, `n`, цена).
- Просмотр результата: зум, навигация, сохранение в файл и копирование в буфер.
- Подтверждение дорогой генерации и лимит расходов за сессию.
- Провайдер-специфичные параметры моделей (passthrough).
- Проверка формата референсных изображений.
- Сетка всех результатов; клик по изображению открывает отдельное окно
  просмотра с зумом, навигацией и экспортом.
- Адаптивная матрица результатов: число колонок пересчитывается по ширине окна.
- Полосы прокрутки в стиле приложения (без стрелок, с подсветкой ручки).
- Иконка приложения (окно и панель задач Windows).
- Провайдер Polza.ai: каталог из 24 моделей, генерация изображений (в том числе
  с референсами) и проверка баланса.
- Переключение агрегатора в верхней панели: выбор сохраняется и перезагружает
  каталог моделей.
- Отдельный ключ API для каждого агрегатора; ключи хранятся локально и не попадают
  в репозиторий.
- Кнопка «Стоп» прерывает ожидание результата, а не только следующий запрос.
- Загрузка справочников агрегаторов: скрипт `scripts/fetch_docs.py` и кнопки
  «Load … docs» в окне документации. Справочники принадлежат владельцам сервисов, не
  входят в репозиторий и обновляются на их стороне, поэтому после клона их нужно
  скачать один раз.

### Исправлено
- В панели параметров появился выбор пропорций (`Aspect ratio`). Раньше его не было
  вовсе, поэтому модели, требующие `aspect_ratio` (например `tongyi-mai/z-image`),
  отклоняли запрос — уже после того, как приложение собиралось потратить деньги.
- Обязательные параметры модели проверяются до отправки запроса: приложение
  показывает, что нужно заполнить, и перечисляет допустимые значения, вместо того
  чтобы платить за заведомо отклонённый запрос.
- Для обязательного параметра больше не предлагается пустое значение `auto` —
  подставляется конкретное, и его можно изменить.
- Модели, которые не умеют генерировать по промпту (например апскейлер
  `topaz/image-upscale`), скрыты из списка; в журнале пишется, сколько пропущено.
- Результат сохраняется даже для моделей с пространством имён в id
  (`x-ai/grok-imagine-image`): раньше слеш в id приводил к ошибке записи файла
  после успешной генерации.
- Polza.ai: запрос на несколько изображений возвращает столько же картинок,
  сколько запрошено. Раньше при `n > 1` приходила одна картинка.

### Улучшено
- Просмотр документации: подсветка синтаксиса в блоках кода, аккуратные таблицы,
  иерархия заголовков, цитаты и панели кода — в светлой и тёмной темах.
- Выделение выбранного документа в списке стало сдержанным: акцентная полоса и
  цветной текст вместо сплошной синей заливки.
- Длинные строки кода переносятся по ширине окна, горизонтальная прокрутка в
  документации убрана.
- Логика рендеринга документации вынесена в модуль без Qt, поэтому тесты проходят на
  машине без графических библиотек.
