# 0.3.0 — деньги, зависания и внятные ошибки

Дата: 2026-10-03

## Что изменилось

### Деньги
- Нажатие **Stop** после того, как агрегатор уже ответил, больше не выбрасывает оплаченную
  картинку.
- Итоги расходов больше не показываются как точные, если часть попыток осталась без
  известной цены.
- Параметры AITUNNEL больше не подставляются молча: приложение считало, что список без
  значения `auto` — обязательный, и отправляло параметр, который пользователь не выбирал.
- Журнал больше не пишет «отмена запрошена» там, где у агрегатора ничего не отменялось.
- Модель, которой ключ не может пользоваться, отвергается до отправки запроса, а не после
  резервирования денег.
- Таймаут генерации означает то, что написано в настройках: бюджет делится между
  задачами, а опрос статуса получает только остаток.
- Случайный 502 при ожидании картинки больше не убивает оплаченную задачу, а в сообщении
  остаётся её номер.
- Истёкшая ссылка на картинку объясняется прямо, а не выглядит как сетевая ошибка.

### Интерфейс
- Окно больше не замирает при загрузке референсов: файлы читаются в фоновом потоке, а
  счётчик показывает прогресс.
- Референсы не держат в памяти полноразмерные картинки.
- Смена агрегатора во время генерации откладывается до конца задачи, а каталог моделей и
  параметры остаются на месте.
- Причины отказов агрегатора показываются его словами; его `warnings` о проигнорированных
  параметрах попадают в журнал.
- HTTP-статусы разобраны по смыслу: «агрегатор занят, можно повторить», «слишком большой
  референс — это наша ошибка», «нет такого endpoint».

### Данные
- Настройки и история пишутся через временный файл с `fsync`, рядом остаётся предыдущая
  версия файла.
- Загрузка документации больше не оставляет обрезанных файлов, кнопка обновления не
  исчезает после первого скачивания.
- Подправленная вручную история больше не ломает приложение.

### Новое
- Шаблон имени сохраняемого файла в настройках.
- Системные уведомления о завершении генерации.
- Проверка типов `mypy` в CI, действия закреплены на SHA, кэш pip, проверка сборки пакета.
- `SECURITY.md` с инструкцией на случай утечки ключа, кодекс поведения, шаблоны для
  ошибок, предложений и pull request, `CODEOWNERS`, `dependabot.yml`.

## Известные ограничения

- **Ставить только из исходников.** Установка из wheel не поддерживается: темы оформления
  лежат рядом с пакетом и внутрь wheel не попадают. Подробности — в
  [`docs/known-issues.md`](docs/known-issues.md).
- Отмена запроса на стороне агрегатора невозможна: приложение сообщает об этом честно.
- Ключи API хранятся открытым текстом в `data/settings.json`.
- Две модели Polza.ai идут без оценки стоимости и без подтверждения — так решено владельцем.

## Проверено

- 503 теста, `ruff` и `mypy` без замечаний.
- Живой прогон Polza.ai: 5 запросов из 5 успешных, файлы и история на месте.
